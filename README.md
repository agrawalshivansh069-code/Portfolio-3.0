# Shivansh OS v2.0 — Personal AI Operating System

A high-fidelity, interactive personal operating system portfolio built for **Shivansh Agrawal** (AI & ML Developer, Full-Stack Software Engineer, and Creative Web Developer).

## 🌟 Key Product Features

- **Living Pixel-Art Sunset Wallpaper**: Three independently moving cloud layers with seamless horizontal loops, stepped pixel mountains, atmospheric perspective, and floating sparkle particles.
- **Atmospheric Boot Experience**: Full-screen skippable boot loader with finite progress bar, real terminal initialization logs, and smooth reveal into the active desktop.
- **Interactive AI Companion**: Draggable bottom-left companion with 7 expressive states (`idle`, `happy`, `sad`, `excited`, `sleeping`, `alert`, `dragging`), Web Audio SFX chirps, safe viewport clamping, and persistent position.
- **Window Manager**: Complete multitasking window system with drag-by-titlebar, z-index focus promotion, minimize, maximize, and responsive mobile sheet reflow.
- **Real Verified Work & Proof**: Flagship projects including *Spider-Sense AI* (Gemini multi-modal AI), *AI Financial Guide*, *SIH Prototype (PS SIH26135)*, and data analytics tools.
- **Verified Hackathons**: Smart India Hackathon (SIH 2025/2026), Economic Times AI Hackathon Round 2 Qualifier, and GFG ByteQuest 2026.
- **Command Palette**: Instant fuzzy search (`Ctrl+K` or `/`) across apps, projects, achievements, and themes.
- **Interactive Whiteboard**: Persistent sticky note canvas using browser `localStorage`.
- **Coordinated Themes**: Day (Pastel Sunset), Night (Indigo Cosmos), and Dark (Cyber Workstation).

## 🚀 Running Locally

No dependencies or build steps required. Simply serve the static directory:

```bash
# Python 3
python -m http.server 8000

# or Node npx
npx serve .
```

Open `http://localhost:8000` in any modern web browser.
